# WARDRIVER

Site do projeto integrador do curso de pós em IoT do IFSP Catanduva. Mostra uma simulação do painel web e do app mobile do WARDRIVER, um dispositivo com ESP32 que mapeia redes Wi-Fi de uma região.

## Acesso 
https://alinevajalegre.github.io/wardriver_site/

## Como está organizado

```
index.html          página inicial, com a demonstração do painel web e do app
sobre.html           contexto do projeto, o problema e a proposta
css/style.css        estilo do site
js/main.js           menu mobile, abas e filtros da demonstração
img/                 imagens usadas no site (mapa e terminal)
```

## Tecnologias usadas

- HTML
- CSS
- JavaScript (sem framework nem biblioteca)
